# 2026-11-03 发行版下架的规则工作区功能

状态：已归档，当前发行界面关闭。

以下功能保留源码与测试，但不再显示在 Android 发行界面：

| 功能 | 原入口 | 集中开关 | 下架原因 |
| --- | --- | --- | --- |
| 修改定位 | 候选卡片“修改定位”与条件编辑器 | `locatorEditor` | 操作含义和结果不符合当前测试预期 |
| 多节点选择 | 截图下方的“这里有多个节点”列表 | `nodeSelectionPanel` | 节点角色、框范围和切换顺序容易造成误解 |
| 当前快照规则面板 | “当前快照命中”、运行条件和本地规则检查 | `ruleSnapshotPanel` | 信息密度过高，且容易被误认为设备执行结果 |

开关定义在 `src/components/AndroidLiteApp.tsx` 的 `ARCHIVED_RELEASE_UI` 中。底层 selector 生成、匹配计算、截图命中框、候选测试和 GKD 导入继续运行；本次只下架上述三块界面。

恢复任一功能时，先把对应开关改为 `true`，再重新执行浏览器检查与 Android 真机验收。不要只改开关就把功能直接发布。
