# T03：重叠节点选择与最终点击范围确认

优先级：P1。类型：实现。状态：实现与浏览器回归完成，待设备验收。依赖：[T01](01-rule-validation.md)。

对应清单 B1、用户故事 13–18；依据：[正式规格](../../specs/rule-authoring-optimization-spec.md)。

## 交付结果

用户可在工作区辨认并切换同区域的文字节点、父节点与其他节点，并清楚看到候选最终执行点击的范围。

## 工作范围

- 复用按坐标查找、祖先关系与同区域候选，增加可读的节点选择列表；显示标签、可点击性及范围。
- 区分选点节点、最终点击节点及上下文高亮；自动选择可点击祖先时呈现变化，允许重新选择。
- 单一明确目标直接继续；多个有意义节点才展示必要的消歧操作，保留现有拖动选点方式。
- 无可用节点时提供重新采集等恢复路径，不把整屏容器包装成稳定目标。

## 代码入口

`src/lib/nodePicker.ts`、`regionCandidates.ts`、`dragMagnifier.ts`、`src/components/ScreenshotCanvas.tsx`、`AndroidLiteApp.tsx`。

## 验收条件

- [x] 标签、父层与广告热区重叠样例中，可以选择不同节点并观察对应候选变化。
- [x] 自动切到祖先时能看到最终点击范围，用户可以改选。
- [x] 列表选择可用；节点编号不是唯一识别信息；单一明确目标无新增必经确认。
- [ ] 缩放、拖动及不同截图尺寸下，选点和最终点击范围仍对齐。
- [x] 无节点、仅整屏容器或范围不可用时如实提示，原快照与草稿保留。

## 验证方式

复用现有节点选择／同区域候选回归，工作区行为检查使用真实匹配；Android WebView 验收拖动、缩放、列表与返回操作。确认正式版复制及扩展目标测试入口仍可用。

## 范围外
