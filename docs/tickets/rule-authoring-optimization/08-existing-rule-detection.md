# T08：提示已有本地规则覆盖与重复

优先级：P2。类型：条件实现。状态：受外部能力阻塞；可用性说明已实现。

依赖：[T01](01-rule-validation.md)、[T02](02-validation-context.md)、[T07](07-local-rules-capability.md)，并且读取接口满足所需契约。对应清单 C1 实现、用户故事 35–37；依据：[正式规格](../../specs/rule-authoring-optimization-spec.md)。

## 交付结果

用户选点后，可以异步获知适用的已启用本地规则是否与当前候选重复或覆盖同一目标，并选择查看或继续创建。

## 工作范围

- 按 T07 已核实契约读取当前应用适用的本地规则，核对启用、范围及版本条件；缺少数据时不得推定适用。
- 复用 T01 对当前快照验证，分别报告表达式重复与不同规则的目标覆盖；支持节点关系仅按已经核实的匹配语义判断。
- 检查不阻塞选点／预览，切换快照、目标或节点后丢弃旧结果；静态覆盖不等于设备已执行。
- 默认查看与继续创建；只有 T07 证明稳定身份和明确更新契约可用时，才实现显式替换，否则不出现该操作。

## 代码入口

`src/lib/deviceApi.ts`、`selectorMatcher.ts`、`gkdTarget.ts`、`src/components/AndroidLiteApp.tsx`。对接的数据结构与端点以 T07 契约为准。

## 验收条件

- [ ] 仅检测本地且适用的规则；禁用、范围不符、版本不符、非法或信息不足各有正确处理。
- [ ] 表达式重复与目标覆盖分别提示，多个规则可查看，不按组名合并身份。
- [ ] 检查延迟不阻塞工作区；旧请求不覆盖新上下文，失败显示未检查而非没有重复。
- [x] 没有读取能力时，降级为可用性说明；复制、测试和导入原路径继续工作。
- [x] 缺稳定身份或更新契约时无替换；存在替换时显式操作且保持字段完整，不改写其他规则组。
- [ ] 订阅规则库完整规则组交付、未测试复制／导入资格及已有来源记录行为不变。

## 验证方式

在设备 HTTP 边界提供 T07 的真实契约样例，内部执行真实验证，覆盖启用条件、重复／覆盖、身份冲突、失败和请求乱序；扩展目标设备上回读确认。仅模拟通过不构成接口可用证据。

## 范围外

远程订阅扫描、自动停用订阅、自动覆盖其他规则组、无契约的更新接口。
