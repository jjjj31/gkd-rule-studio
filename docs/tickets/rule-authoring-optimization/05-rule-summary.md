# T05：展示与最终规则一致的简短摘要

优先级：P1。类型：实现。状态：实现与浏览器回归完成，待设备验收。依赖：[T02](02-validation-context.md)。

对应清单 B3、用户故事 27–30；依据：[正式规格](../../specs/rule-authoring-optimization-spec.md)。

## 交付结果

用户不阅读 JSON5，也能看到候选的目标、动作、适用范围与关键执行限制。

## 工作范围

- 从装配后的有效规则字段生成摘要，正确处理规则组继承；未知或无法概括的字段不伪造结论。
- 将摘要放在候选常用视图，选择器、分数与完整 JSON5 保留在详情，避免常驻长篇教程。
- 说明匹配窗口的重置时点；沿用开屏、入页及周期弹窗等场景差异。

## 代码入口

`src/lib/ruleDraft.ts`、`actionPlan.ts`、`candidateGuidance.ts`、`src/data/ruleSettings.ts`、`src/components/AndroidLiteApp.tsx`。

## 验收条件

- [x] 摘要准确表达目标、动作、适用范围，以及存在的时间／次数限制。
- [x] 组级继承和规则级覆盖被正确解释，摘要与实际测试、复制、导入内容一致。
- [x] 周期弹窗不被描述成开屏短窗口；匹配时间不被解释为每次弹出重新计时。
- [x] 复杂字段可看完整原文，常规操作不增加必经确认或长篇说明。
- [ ] 正式版复制、扩展目标导入及订阅规则库原有操作资格保持一致。

## 验证方式

用代表性场景的最终 App 规则断言摘要语义及对外交付内容；工作区检查简短视图与详情切换。纯展示变化不另建测试框架。

## 范围外

调整场景默认值、策略排序或将所有规则压成同一种模板。
