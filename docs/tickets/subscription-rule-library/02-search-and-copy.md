## 交付结果

用户不连设备、不选快照即可从首页搜索应用，按来源查看规则组原名称和说明，并复制一组完整的 App 规则 JSON5 片段。

## 工作范围

- 首页增加独立规则库入口，提供来源添加、手动刷新、删除与缓存状态。
- 应用名子串搜索，兼容空白和英文大小写；包名可辅助定位。相同包名跨来源聚合，同名不同包名保持独立。
- 应用详情按来源展示完整规则组；显示来源、版本、名称、说明、条数和状态。
- 每组提供独立操作位置；复制在未测试、未连接时可用，测试和一键导入由后续 ticket 接入并明确当前可用状态。
- 复制带包名、应用名和完整所选组的 JSON5 正文；来源以注释或单独元数据保留，复制内容可直接用于 GKD 本地应用规则添加。
- 完成返回导航、无来源、无结果、加载中、离线缓存、失败重试和不支持组的提示。

## 代码入口

- `src/components/AndroidLiteApp.tsx`：首页／工作区视图和设备连接状态；独立入口不能沿用必须选快照后才能进入的门槛。
- `src/lib/clipboard.ts`：现有 Android 桥及浏览器剪贴板路径。
- `src/styles.css`：沿用当前移动端界面。
- T1 提供的缓存、应用列表与完整单组交付对象。

## 验收条件

- [ ] 首页直接进入规则库，无需设备、快照或 AI session；返回路径正常。
- [ ] 跨来源同包名应用正确聚合，别名可搜索；同名不同包名分别显示；同名组不合并。
- [ ] 组名／说明保留原内容，来源与版本清楚；默认禁用、无结果和无来源状态可理解。
- [ ] 断网和重启后仍可查缓存；失败来源可重试，正常来源仍可浏览。
- [ ] 未测试、无设备时可复制，反馈真实；剪贴板正文经 JSON5 回读仅含所选完整组及对应应用信息。
- [ ] 缺外部依赖的组可浏览并说明限制，避免输出不完整可执行片段。
- [ ] 有针对跨来源身份、名称匹配和复制完整性的测试；完成 Android WebView 的导航及离线复制检查，受影响的已有检查通过。

完成时留下界面截图或操作记录、复制示例及验证结果。批量勾选、复制订阅链接代替所选规则正文不属于此 ticket。
