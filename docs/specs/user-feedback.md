## 用户流程

- 面向 Android：首页与测试结果提供「反馈」；工作区不再提供独立反馈入口。分类为工具故障、规则效果问题、希望有的功能。
- 无需用户登录。问题描述必填；邮箱／QQ 等联系方式选填。
- 自动整理工具版本、系统版本、GKD 版本类型与版本号、相关错误；当前规则、截图、节点树和 GKD 诊断压缩包默认不附带，用户决定是否选择。
- 「当前规则」支持选择 JSON、JSON5 或 TXT 文件，同时保留粘贴和编辑入口。GKD 测试版可在「设置 → 诊断 → 诊断采集」停止采集后导出 ZIP，再由用户手动选择上传；ZIP 原样附带，预览中明确提示可能包含规则、节点文字和运行日志。
- 截图支持框选不透明遮挡，对应节点的文字、描述等字段同步隐藏；文字材料支持编辑或隐藏字段。已知 API Key 等凭证自动排除。
- 上传前必须预览最终脱敏材料；原始截图和被隐藏内容不上传。
- 成功后显示反馈编号；不提供用户侧反馈历史或站内回复。
- 失败保存已脱敏的本地草稿，由用户再次预览后手动重试；可主动删除草稿。服务端用提交标识避免网络重试生成重复反馈。
