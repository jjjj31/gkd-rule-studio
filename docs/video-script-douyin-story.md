# 抖音宣传视频脚本（第一人称）

目标：用 30–45 秒讲一个“被广告逼疯 → 找到 GKD → 规则太难 → 发现 Rule Studio → 一步生成规则”的完整故事。

节奏参考：抖音短视频完播率最高的是 20–35 秒，配合快剪和字幕。每个镜头 1–3 秒，总镜头数控制在 12–15 个。

---

## 一、整体叙事结构

| 段落 | 时长 | 情绪 | 目的 |
| --- | --- | --- | --- |
| 开场钩子 | 0–3s | 烦躁、共鸣 | 让刷到的人立刻想起自己被广告逼疯的时刻 |
| 探索 | 3–10s | 好奇、挫败 | 引出 GKD 和“规则不会写”的痛点 |
| 转折 | 10–13s | 惊喜 | 搜到 Rule Studio，引入工具 |
| 展示 | 13–28s | 兴奋、想拥有 | 演示核心功能，让人看懂“能干嘛” |
| 收尾 | 28–35s | 期待 | 给下载理由和行动指令 |

## 三、旁白文案（可直接录音）

> 真的会谢，看个视频 3 个弹窗，手都划麻了。我不信没人管这事，直接搜。还真有个东西，叫 GKD。结果打开订阅库——没有我用的 App。好，那我自己写。搜了半天教程……我是真看不懂。换个思路，搜“规则制作工具”，还真让我找到了。连上 GKD，拖一下放大镜，选广告按钮。松手瞬间，14 条候选自动排序，直接选最推荐的。一键测试，广告真的没了。导入 GKD，以后再也不用手动关。多步操作也能做，连续弹窗一起解决。工具我放评论区，想跳广告的自己去找。

旁白总字数约 160 字，正常语速 35 秒左右，符合 30–40 秒短视频节奏。

### 字体 / 图标 / 音效

- 字体：抖音热门风格常用「思源黑体」或「阿里妈妈方圆体」，加描边或阴影提高可读性。

- 图标：从 `docs/images/` 已有截图或 App 图标里取，不要额外设计。

## 五、拍摄 / 制作建议

1. **AI 动画风格统一**：所有动画镜头用同一个风格关键词（如“flat illustration, dark tech theme, 9:16”），避免不同镜头画风割裂。
2. **真实录屏优先**：镜头 7–10 用真实操作，比 AI 模拟 UI 可信得多，也更容易让观众知道“这工具真的能用”。
3. **字幕全程覆盖**：抖音大量用户静音刷视频，旁白文案要同步做字幕，关键词用大字强调。
4. **BGM 卡点**：在镜头 3、6、9、12 的转场做音乐卡点，提升完播率。
5. **发布文案**：
   > 看个视频 3 个弹窗，忍不了了。搜了一圈终于找到能自己做规则的工具，连 GKD 都能用。评论区自取。
6. **标签**：`#GKD #跳过广告 #安卓神器 #效率工具 #开源`

## 六、验证与迭代

1. 用合成数据先过一遍分镜，确认每个镜头都有对应素材。
2. 真机录屏镜头 7–10，确认操作步骤能看清楚，不加速太多。
3. 剪辑时按脚本时长对齐旁白，超时就删镜头 11（多步规则），优先保住核心转化链。
4. 发布后看 3 秒完播率和平均观看时长，如果 3 秒流失高，优先改镜头 1。
