## 复现与判断

连接真实 Android WebView，通过 ADB 转发调试接口，向同一个添加来源入口提交受控 HTTP 响应：响应头和正文首字节立即发送，其余正文延迟 45 秒。

- 修复前：响应头约 56 毫秒到达，40,188 毫秒后添加按钮仍被禁用，未提示超时。
- 原因：通用 fetch 超时在收到响应头时就取消计时，后续 `response.text()` 没有下载期限。慢速或停滞的正文下载让来源任务长期占用操作锁。
- 排除路径：受控响应尚未完成正文传输，因此此复现中的卡住发生在解析和缓存保存之前。
- 原始公网链接 `https://gkd-subscription-667.pages.dev/gkd.json5` 首次诊断重试约 10.8 秒成功；公网故障具有间歇性，未捕获用户最初那次网络传输，不能确定当时服务器或网络的具体异常。
