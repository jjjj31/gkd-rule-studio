GKD Rule Studio 便携版

使用方法
1. 解压整个文件夹。
2. 双击 START.cmd。
3. 浏览器会自动打开 http://127.0.0.1:5174/。
4. 启动窗口会停在提示界面，按任意键只会关闭启动窗口，不会关闭后台服务。
5. 如果要关闭后台服务，双击 STOP.cmd。

订阅仓库写入
1. Windows 便携版支持把当前生成的规则写入本地 GKD 订阅仓库。
2. 请用 Edge / Chrome 打开 http://127.0.0.1:5174/。
3. 在工作区右上角打开设置，进入“订阅仓库”。
4. 点击“连接本地订阅仓库”，选择包含 package.json 和 src/apps 的仓库根目录。
5. 点击“写入当前规则”后，工具会写入 src/apps/<应用包名>.ts。
6. 历史导入记录里可以单独撤回某次写入。
7. 详细教程见同目录的“订阅仓库写入教程.txt”。

手机连接建议
1. 优先使用首页的“ADB 数据线”方式。
2. 手机需要开启开发者选项和 USB 调试。
3. 第一次连接时，手机上会弹出 USB 调试授权，请点允许。
4. 如果 ADB 检测不到设备，可以安装 Android Platform Tools，或把 adb.exe 放到本工具目录的 adb\adb.exe。

HTTP 服务说明
1. 如果使用 GKD 的手机 HTTP 服务，手机和电脑需要在同一网络。
2. 部分浏览器跨域限制会导致 HTTP 服务不稳定，建议优先试 ADB。

隐私说明
1. 工具默认在本机运行。
2. 快照、截图、节点树不会上传到作者服务器。
3. 复制求助 prompt 给 AI 前，请自行检查是否包含隐私内容。

日志位置
- logs\web.log：前端本地服务日志
- logs\adb-helper.log：ADB 辅助服务日志

常见问题
1. 打不开页面：双击“便携版-停止.cmd”后重新启动。
2. 端口被占用：检查 5174 或 18741 是否被其他程序占用。
3. ADB unauthorized：看手机屏幕，允许 USB 调试授权。
4. 找不到 adb：安装 Android Platform Tools，或把 adb.exe 放到 adb\adb.exe。
